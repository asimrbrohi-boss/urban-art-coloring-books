# KDP Print Specifications

## Recommended book setup
- Trim size: 8.5 x 11 in
- Interior: black and white line art
- Paper: standard white paper for coloring books
- Print color: black-and-white interior
- Bleed: if using background art beyond page edges, add safe bleed margin as required by KDP
- Page count: 25 pages plus cover

## Layout guidance
- Use portrait orientation
- Keep main art centered with generous margins
- Avoid text too close to the page edges
- Use no grayscale shading unless intentionally part of the design
- Keep line weight consistent across all pages

## KDP-ready file requirements
- Export final interior as a high-resolution PDF
- Ensure the PDF is print-ready and not a web file
- Set all artwork to pure black line art on white background
- Check that pages are not mirrored or rotated
- Review final output at full scale before uploading

## Design checklist
- Every page should feel crisp at print size
- Character silhouettes remain recognizable when reduced to small size
- Background elements do not overpower the main subject
- No hidden text or elements within fine lines
- Clean separation between line art and white space

## Publishing tips
- Use a consistent visual style across the book for series branding
- Consider creating a matching cover and title series design
- Build 2–3 related titles rather than a single standalone book
- Test the print size in a preview before publishing

## Recommended file naming
- 01_cover_final.pdf
- 02_interior_urban_jungle.pdf
- 03_back_cover_final.pdf
