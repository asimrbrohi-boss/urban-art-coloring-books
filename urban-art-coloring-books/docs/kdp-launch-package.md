- Start with a personal Amazon KDP account
- You do not need a separate business account to begin
- Keep the author/publisher branding simple and consistent across the series
- Register a formal business later if you want a more official brand identity

## KDP print setup
Trim size: 8.5 x 11
Interior: black-and-white
Paper type: white paper
Binding: standard paperback
Page count: 25 interior pages plus cover
Format: PDF print-ready
Resolution: 300 DPI minimum
Color: black-and-white only

## File checklist
- Front cover file ready
- Back cover file ready
- Interior PDF prepared
- All pages checked for print clarity
- White background preserved
- Black lines are strong and consistent
- No gray shading or gradients
- File names finalized and organized

## Upload checklist
1. Create Amazon KDP account
2. Add tax and banking details
3. Upload the interior PDF
4. Upload the cover file
5. Add book title, subtitle, and series name
6. Write the description
7. Add keywords and audience
8. Review preview
9. Set price
10. Publish

## Recommended next action
Create the cover mockup and first five page batch as the initial proofs, then upload them to KDP once the print preview is confirmed.
